# Ảnh điểm đến — nguồn và giấy phép

Mọi ảnh trong thư mục này lấy từ [Wikimedia Commons](https://commons.wikimedia.org/). Giấy phép của từng ảnh được đọc trên trang file Commons của ảnh đó (mục *Licensing*) khi tải về, ngày 2026-10-02.

**Các ảnh này KHÔNG thuộc giấy phép thương mại của LuxeStay.** Mỗi ảnh theo giấy phép riêng ghi dưới đây. Khi dùng ảnh CC BY / CC BY-SA phải ghi tên tác giả và giấy phép (trang web làm việc đó trên thẻ điểm đến và ở trang `/credits`). Ảnh CC BY-SA đã chỉnh sửa (thu nhỏ, nén) vẫn theo CC BY-SA cùng phiên bản.

`credits.json` chứa cùng thông tin dưới dạng dữ liệu; `npm run db:seed` đọc file đó.
