# Sample room photos

Put the bundled sample photos for `npm run db:seed` in this folder
(`.jpg`, `.png` or `.webp`). The seed copies them into `uploads/rooms/` and
assigns them to the sample rooms in filename order: one cover plus up to
three gallery photos per room, cycling through the set.

With no photos here the seed still works; rooms are created without images
and the site shows its placeholder image instead.

Only add photos you are allowed to redistribute with the source code.
