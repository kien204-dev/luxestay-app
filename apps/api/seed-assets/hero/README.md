# Home page background

Put one landscape photo here (`.jpg`, `.png` or `.webp`, ideally about
1600–2000 px wide and under 2 MB) and `npm run db:seed` makes it the
background of the home page search area, unless one is already set. The
first file in name order is used. None is bundled.

An admin can also set or change it under /admin/property.

Only add a photo you are allowed to redistribute with the source code, and
record its licence next to it.
